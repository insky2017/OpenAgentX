# OpenAgentX 本轮功能收口后的计划

## 基线

- 用户要求先交付指挥台配置、运行、观察和结果的可用闭环；已完成改动保留，不回退。
- 本计划记录尚未完成或证据不足的后续事项，不改写冻结 ADR，也不把本轮功能验收等同于全部 ADR 要求完成。
- 主流程失败、秘密泄露/权限绕过、覆盖他人/重复执行/误删有效引用、虚报应用或核验成功仍须本轮修复。

## 后续事项

| 事项 | 当前边界或临时处理 | 后续验收重点 |
|---|---|---|
| 秘密与文件恢复加固 | 保留已完成的目录 fd、原子 key、引用检查及扫描；受控且正式 API 不可读的孤立文件可暂存 | 更多崩溃组合、扫描性能、长期清理与引用一致性；不误删历史/活动引用 |
| 网络配置易用性与兼容 | 本轮完成已声明模式的日常配置；删除凭据可先新建无认证方案并重绑 | 更丰富的导入兼容、显式移除凭据、批量管理与高级配置 |
| 扩展竞态与故障矩阵 | 本轮验证关键 CAS/幂等、实际回执与活动 Run 固定版本 | 十类命令更完整的独立脚本、组合安全错误、极端并发与故障注入 |
| 历史观察与分析 | 本轮呈现 Task/Run/Worker、阶段、错误和结果；已有分页能力保留 | 更完整的历史查询、复杂时间线、统计与跨运行对照 |
| 产物与长内容 | 本轮提供安全 Markdown、原文/复制及结果正文；超限明确提示 | 受控短期产物、复杂展示、完整长内容按块处理及性能优化 |
| 业务副作用核验 | 最小纠正错误状态映射，区分 Runtime 自报与已核验事实，未确认时保留 uncertain | 独立设计窄类型、带 CAS/审计的业务核验入口；不允许 Runtime 自报提升可信等级 |

## 推进规则

- 后续逐项确认实际影响、范围、验收和归属，不因旧严重级别标签自动扩大任务。
- 已有实现与证据复用；只对发生变化或仍有明确疑点的边界补验。
- 最终功能报告列出剩余事项和未覆盖范围，后续任务完成后追加新证据，不覆盖历史失败。
