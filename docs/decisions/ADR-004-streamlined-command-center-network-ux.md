# ADR-004: 指挥台网络配置体验极简收敛与路由器模型

## 状态

已接受 (Accepted)

## 日期与决策者

- 日期：2026-09-06
- 决策者 / 所有者：OpenAgentX Team / OpenAgentX Maintainer

## 背景

在 ADR-002 中，OpenAgentX 建立了严格的 Runtime 网络出口安全与控制机制，包括配置不可变版本、Secret 密文隔离、CAS 乐观并发控制、幂等变更指令、RunAttempt 策略快照隔离以及 Fail-closed 约束。

但在早期的移动指挥台前端实现中，过多底层分布式控制面机械细节被直接暴露在 UI 上：
1. **心智模型过于繁琐**：配置过程被拆解为“创建草稿”、“目标 Worker 探测测试”、“发布版本”、“绑定策略”、“历史回滚”等分散步骤，用户需多次手动在不同区块间切换操作。
2. **信息噪音过载**：界面展示了多列连通性探测历史瀑布流、历史版本回退矩阵、Worker 本地策略一次性导入面板等调试信息。用户在日常运维中仅需知道“当前连通性如何”以及“是否正常生效”。
3. **移动端体验不友好**：目标 Runtime 下拉菜单中包含 80 字符的内部 Worker UUID 和 Generation 哈希；桌面端的多列网格在手机屏幕上产生溢出与换行错位。

用户提出明确诉求：网络配置应该像家用路由器或手机 Wi-Fi/代理配置一样简洁直观，作为可供 Runtime 绑定与选择的选项库，隐藏繁琐的分布式测试历史与版本表，仅展示当下测试结果与生效状态。

## 决策

### 1. 路由器两卡片心智模型 (Router Two-Card Model)

将网络配置界面全面收敛为上下两张现代卡片：

1. **Runtime 出网配置 (Runtime Network Card)**：
   - **目标选择**：仅显示人类可读的友好标识（如 `quote-service (主服务)`），隐藏底层 Worker 机器 UUID。
   - **出网模式切换**：大触控热区的药丸切换组（`系统默认 (inherit)`、`直接出网 (direct)`、`走代理服务器 (named_profile)`）。
   - **代理节点下拉**：选择 `走代理服务器` 时展开代理选择下拉框，清晰标注协议类型、地址及密码状态。
   - **一键测试与应用**：提供 `[ ⚡ 测试连接 ]` 与 `[ 保存并应用 ]` 两个主要操作入口。
   - **状态简报与运行保护**：以单行简报形式显示“实际生效”状态与当次测试状态小圆点（含延迟耗时）；在有进行中的任务时，以警示横条提示任务快照保护。

2. **代理池管理 (Proxy Pool Card)**：
   - 集中展示当前可用的 HTTP / SOCKS5 代理服务器节点与安全凭据状态，作为底层出网节点的选项资产库（出网绑定统一在顶部“Runtime 出网配置”下拉中按需选择）。

### 2. 前端单动作自动流水线 (Single-Action Auto Pipeline)

为了在保持极简心智的同时完全继承 ADR-002 的分布式高可靠与安全性，前端通过复合流程自动协调底层后端状态机：

- **⚡ 测试连接**：
  - 若当前选中的代理已是 `ready` 或 `published`，直接使用目标 Worker 执行模式探测。
  - 若为新修改的草稿，前端自动按序发起创建草稿 ➔ 执行目标连通性测试，并将探测耗时与诊断码即时反馈在“测试结果”徽标中。
- **保存并应用**：
  - 点击“保存并应用”时，如果选中的代理方案处于 `ready` 草稿状态，前端自动在后台将其原子升级为 `published`，紧接着发起 `PUT /api/v1/network/bindings/{agent_id}`，使用最新的 expected-version 与 Idempotency-Key 完成策略绑定。
  - 用户无需感知草稿、测试、发布、绑定的阶段切换，体验与普通路由设置保持一致。

### 3. 全面剔除控制面调试噪音

彻底从指挥台日常页面中移除下列非必要机制与视图：
- **移除连通性测试历史瀑布流**：不保留多条滚动的历史测试记录，仅在简报行显示“当前/最近一次测试结果”。
- **移除多列探测结果矩阵与详细探针列表**。
- **移除版本回滚历史表**：简化为当前生效版本对比，出现版本冲突时引导刷新。
- **移除“从选中 Worker 一次性导入”面板**：系统初始化或导入操作收敛至后端启动时或专用 CLI/Admin 工具，不在日常出网配置界面占据主视觉。

### 4. 移动端优先与触控人体工程学

- 所有交互控件（模式药丸、下拉菜单、操作按钮）触控高度均不小于 44px。
- 在屏幕宽度 $\le 640	ext{px}$ 时：
  - 模式药丸自适应单列排列，避免文本折行拥挤。
  - 操作按钮组垂直堆叠，按钮宽度 $100\%$ 便于单手大拇指快速触控。
  - 代理卡片采用垂直上下结构，左侧协议与名称，右侧密码标签与选用按钮横向贴合，彻底杜绝横向滚动条。

### 5. 继承 ADR-002 安全与合规底线

本 ADR 仅重构呈现层与交互流水线，严格保留 ADR-002 的全部后端核心约束：
- 凭据秘密必须经过加密存储并以 `secret_present` 脱敏传输，禁止在前端源码或明文日志中暴露。
- 策略下发与修改必须遵循 CAS expected-version 校验，防止并发冲突覆盖。
- 任务执行时对网络的快照绑定不变，保证活动任务不会因为界面修改而产生瞬态网络震荡。

## 影响与后果

### 正向收益

- **认知负荷大幅降低**：用户配置代理的操作步骤从原本的 4~5 次不同区域确认减少到只需“选节点 ➔ 测连接 ➔ 保存应用”。
- **移动端可用性显著提升**：在手机指挥台上布局紧凑、层级清晰，无视觉溢出与长字符串打乱布局的情况。
- **安全性与稳定性零妥协**：底层依然受 ADR-002 事务与状态机保护。
